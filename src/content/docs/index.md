**29 California statutory codes plus the California Constitution**, with the complete
statutory text of every code organized by its official divisions.

- **Browse** any code from the [code catalog](/codes/) or the sidebar.
- **Search** the full text of every code from the search bar (Ctrl-K).
- **Ask AI** research questions against the corpus on the [Ask AI page](/ask/) —
  wired for Sarvam AI, OpenRouter, or Mistral.
- **Download** any code as `JSONL.gz` from its overview page.
